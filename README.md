This repository is a personal learning workspace for practicing deep learning concepts, implementations, and experiments. I will add code, notebooks, and small projects here as I study and build models step by step.

## Purpose

The goal of this repo is to:

- practice fundamental deep learning concepts
- implement models from scratch and with libraries

- document learning progress in a structured way

## Environment Setup

Use Python 3.10+ and create a virtual environment:

```bash
python -m venv venv
source venv/bin/activate
pip install --upgrade pip
```

Install commonly used deep learning packages:

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

If you are working with frameworks like PyTorch or TensorFlow, install them separately depending on your system and hardware:

```bash
pip install torch torchvision torchaudio
```

or

```bash
pip install tensorflow
```

## Running Code

Navigate to the relevant folder and run the scripts or notebooks:

```bash
cd perceptron
python your_script.py
```

For notebooks:

```bash
jupyter notebook
```

## Learning Workflow

1. Read and understand the concept.
2. Implement the idea in code.
3. Test with small datasets.
4. Visualize results when possible.
5. Refactor and improve the implementation.
6. Document findings in comments or notes.
